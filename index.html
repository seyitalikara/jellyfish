Firebase Kurulumu

Çoklu cihaz desteği için ücretsiz Firebase hesabı bağlayın.

Nasıl Yapılır?

  1. console.firebase.google.com adresine gidin
  2. "Add project" ile yeni proje oluşturun
  3. Realtime Database → "Create database" → "Locked mode" seçin, Rules sekmesine database.rules.json içeriğini yapıştırın
  4. Authentication → Sign-in method → Anonymous girişini etkinleştirin
  5. Project Settings → "Web app" ekleyin → config kopyalayın
  6. Aşağıdaki alanlara yapıştırın ve kaydedin

Config bilgileri bu tarayıcıya kaydedilir. Kalıcı çözüm: index.html içindeki EMBEDDED_CONFIG bölümünü doldurun.
